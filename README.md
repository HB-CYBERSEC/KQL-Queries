# KQL-Queries

KQL for Microsoft Defender XDR / Microsoft Sentinel

This repository hosts Kusto Query Language (KQL) content tailored for Microsoft Defender XDR and Microsoft Sentinel. You’ll find (or soon may find) ready-to-use Threat Hunting queries, Detection Rules, and Visualizations to accelerate investigations, improve detections, and support reporting. Contributions and PRs are welcome—please include a brief description, required tables, and any testing notes.
